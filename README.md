# social-media-app-react
✅ Complete Features:
🔐 Authentication System

User login with existing accounts
User registration with username, name, and bio
5 demo accounts pre-loaded

📝 Post System

Create posts with text and emoji images
Like/unlike posts with heart animation
Comment on posts
Real-time timestamp display
Post feed showing friends' posts

👥 Friend Request System

Send friend requests
Accept/reject requests
Pending request indicators
Friend status badges
View all users and discover new friends

🔔 Notifications System

Real-time notifications for:

Friend requests
Accepted friend requests
Post likes
Comments on posts
New posts from friends


Unread notification badges
Notification dropdown panel
Mark as read functionality

🎨 User Interface

Feed Page: Create posts, view friends' posts, like & comment
Friends Page: Manage friend requests, discover new users
Profile Page: View your posts, stats, and profile info
Beautiful gradient design
Responsive layout
Smooth transitions and hover effects

⚡ Real-Time Features (Simulated)

Instant notification updates
Live post feed updates
Real-time like/comment counts
Friend status changes

🎯 How to Use:

Login: Click any demo user to login
Create Account: Click "Create new account" to sign up
Post: Write your thoughts and select an emoji image
Connect: Send friend requests to other users
Engage: Like and comment on posts
Notifications: Click the bell icon to see updates

Note: This is a fully functional client-side demo. In a production environment, you would add:

Backend API (Node.js + Express)
Database (MongoDB/PostgreSQL)
Real WebSockets (Socket.IO)
Image upload functionality
Authentication with JWT
Password encryption

💻 To Run It Locally on Your Computer:
If you want to run this on your own machine, follow these steps:
Option 1: Quick Start (Recommended)

Copy the code from the artifact
Go to CodeSandbox or StackBlitz
Create a new React project
Replace the default App.jsx with the code
Click Run - it will work instantly!

Option 2: Local Development Setup
bash# 1. Create a new React app
npx create-react-app social-network
cd social-network

# 2. Install required dependencies
npm install lucide-react

# 3. Replace src/App.js with the artifact code

# 4. Start the development server
npm start
The app will open at http://localhost:3000
